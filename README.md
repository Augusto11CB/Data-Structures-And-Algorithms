# Data Structures and Algorithms

Personal study material and practice solutions for data structures and algorithms.

## Repository map

- [Theory](theory/README.md) — curated explanations, implementations used for illustration, and reference material.
- [Practice](practice/README.md) — executable problem solutions, organized by topic rather than by the platform that supplied a problem.
- [Courses](courses/README.md) — notes, assignments, and material retained in their original course context.
- [References](references/README.md) — concise language-specific algorithm cheat sheets.

## Finding a practice problem

Use the [practice index](practice/INDEX.md) to search by problem, topic, source, or review date. A later reimplementation belongs beside the original solution and should use a review date in its name, for example `Review2026_09.java`.

## Conventions

- Keep conceptual material in `theory/`.
- Keep new executable problem solutions in `practice/`.
- Keep course-specific notes and historical submissions in `courses/`.
- Preserve the original source of a problem in the practice index or its documentation; do not use the source platform as the repository's main organizational boundary.
