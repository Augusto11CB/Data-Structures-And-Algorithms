### Exercise 1: Online Store Application
**Task:** Design and implement an online store application that includes product management, order processing, and user accounts.

**Requirements:**
- **Product Management:** Create classes for products and categories. Implement filtering and sorting functionality using the Strategy and Factory patterns.
- **Order Processing:** Use the Observer pattern to notify users of order status updates. Apply the Chain of Responsibility pattern to handle different stages of order processing.
- **User Accounts:** Implement user authentication and authorization using the State pattern for user states (e.g., Guest, LoggedIn, Admin).
- **SOLID Principles:** Ensure that the design adheres to SOLID principles by applying the Single Responsibility Principle (SRP) for separate classes handling different concerns, the Open/Closed Principle (OCP) for extensible product and order management, and Dependency Inversion Principle (DIP) for user authentication.
