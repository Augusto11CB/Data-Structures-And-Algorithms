# Practice index

This index is the starting point for locating and revisiting problem solutions. The source platform is recorded as metadata; directories are organized by the data structure or algorithmic technique used.

## Reimplementation convention

Keep a reviewed solution in the existing problem package. Retain the original as `ProblemSolution.java` and name later attempts with the review date, such as `Review2026_09.java`. This keeps attempts comparable without creating a second copy of the problem elsewhere.

## Add a problem

1. Put the solution in the existing topic package, or create a new topic package when necessary.
2. Add the problem title, source, topic, and last-review date to the relevant table below.
3. On a revisit, add a dated `ReviewYYYY_MM.java` implementation in the same package and update the review date.
